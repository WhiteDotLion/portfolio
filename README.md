# Portfolio de Bayron Escalante

Portfolio profesional desarrollado con React, TypeScript, Vite y Tailwind CSS.

## Desarrollo local

```bash
npm install
npm run dev
```

## Validación

```bash
npm run lint
npm run build
```

## Estructura

- `src/components`: componentes reutilizables.
- `src/sections`: secciones principales de la Home.
- `src/data`: contenido y configuración editable.
- `src/types`: tipos compartidos.
- `public`: recursos estáticos como el CV y capturas reales.

Los enlaces de contacto y la ruta del CV se configuran en `src/data/portfolio.ts`.
